# Sales Document Setup — Information Needed From the Dealership

The sales-document feature ships with clearly labeled **demonstration templates only**.
Nothing generated by the system should be treated as legally sufficient until the items
below are provided and configured. An owner-only setup checklist inside the application
mirrors this list and remains visible until configuration is complete.

## Needed from Gold Country Classic Cars

1. **Approved document list** — the exact set of sales, buyer, seller, consignor, title,
   registration/DMV, transport, and closing documents the dealership uses, for both
   dealer-owned and consignment deals.
2. **Approved templates** — the current, legally reviewed version of each document
   (PDF or Word), with an effective date.
3. **Applicability rules** — when each document applies: deal type (owned vs. consignment),
   buyer registration state, delivery state, vehicle age, payment method, transport method,
   or other conditions.
4. **Required fields** — every field each template needs filled, and which party supplies it.
5. **Required signers and signing order** — buyer, co-buyer, seller, consignor, dealership
   representative; and who signs first.
6. **Allowed signature methods per document** — electronic signature eligibility, wet
   signature requirement, original-document requirement, notarization requirement.
7. **Filing destinations and retention** — where each completed document is filed
   (DMV, internal archive, lender, consignor) and how long it must be retained.
8. **California dealer compliance review** — confirmation from the dealership's legal or
   compliance resource that the configured package satisfies current California DMV and
   dealer requirements (e.g., required disclosures, smog/emissions rules where applicable,
   FTC Used Car Rule / Buyers Guide applicability for the vehicles sold).
9. **E-signature vendor selection** — which provider (if any) to integrate; the system
   ships with a development mock and a provider-neutral adapter interface.
10. **Consignor settlement deadline policy** — the number of days after sale funds clear
    within which consignors must be paid (configurable in Administration; the system does
    not hardcode a legal conclusion).

## What the system does in the meantime

- Document preflight, generation, versioning, snapshotting, audit, and signature-task
  tracking all work against demonstration templates.
- Every demonstration document is watermarked and labeled
  "DEMONSTRATION — NOT AN APPROVED LEGAL DOCUMENT".
- Sending is a deliberate multi-step flow (generate → review → confirm recipients →
  confirm package → send) and, in development, routes to the mock e-signature adapter
  which never contacts a real service.
